# Z-City Back Holster

Аддон для Garry's Mod / Z-City: ближнее оружие из белого списка (топор,
лом, бита и т.п.) носится на спине, вместо того чтобы выбрасываться.

## Возможности

- На спину можно положить только оружие из белого списка `lua/holster/positions.lua`
  (сейчас: топор, кувалда, лопата, копья, топорики, лом, бита, мачете) —
  всё остальное (бутылки, палки, посуда, огнетушитель и т.п.) туда не попадает.
- Одновременно носится только одно такое оружие: подобрав новое, вы выкидываете старое.
- Оружие за спиной не выбрасывается при неявных дропах (например, когда ZCity сам
  выбрасывает переносимое оружие через `homigrad-dropholstered`) — аддон сам
  перехватывает этот стоковый хук, править игру не нужно.
- Двуручные стволы (`TwoHanded` / `bigNoDrop`) никогда не выбрасываются неявно —
  даже вместе с другим оружием.
- Явный дроп (команда `drop` / `dropweapon`, радиальное меню) выбрасывает только то
  оружие, которое просили выбросить, и ничего лишнего.
- Отображение (модель, кость, позиция, поворот) настраивается в отдельном файле
  **`lua/holster/positions.lua`** — код трогать не нужно.

## Структура

```
addon.json                                  -- метаданные аддона для GMod
lua/
  autorun/
    client/zcity_holster_cl.lua             -- отрисовка модели на спине / на рагдолле
    server/zcity_holster_sv.lua             -- правила переноса и дропа на сервере
  holster/
    positions.lua                           -- ← ГЛАВНЫЙ список back-оружия + позиции
```

## Установка

1. Положите папку этого репозитория в `garrysmod/addons/` и переименуйте её
   в `zcity_holster` (или склонируйте:
   `git clone <url> garrysmod/addons/zcity_holster`).
2. Перезапустите сервер / смените карту (или выполните `changelevel`).
   Ручные правки файлов Z-City **не требуются**: аддон сам перехватывает
   стоковый хук `homigrad-dropholstered` из `sv_util.lua` (единственный эффект —
   back-оружие больше не выбрасывается), дублируя правку, которую раньше нужно
   было вносить в игру вручную.
3. Для выделенного сервера без мастерской файлы отдаются клиентам автоматически
   через `AddCSLuaFile` (см. начало `zcity_holster_sv.lua`). Если клиент не видит
   оружие на спине — убедитесь, что аддон установлен и на его стороне.

> `sv_util сервер.lua` — серверная копия `sv_util.lua` из Z-City, из которой
> правка переехала в аддон (оставлена как справка, в игре не нужна).
> `archive.zip` — архив оригинального `z_city`, на который опиралась разработка.

## Редактирование списка и позиций отображения

Откройте **`lua/holster/positions.lua`**. Это единственный файл, который определяет,
какое оружие можно носить за спиной, и как оно там выглядит. Каждая запись:

```lua
weapon_hg_axe = {
    bone = "ValveBiped.Bip01_Spine2",  -- кость, к которой крепится модель
    pos  = Vector(-4, 5, 4),           -- смещение (вперёд, вправо, вверх)
    ang  = Angle(0, 90, 160),          -- поворот (pitch, yaw, roll), градусы
},
```

- `bone` — кость игрока; для спины это `ValveBiped.Bip01_Spine2`.
- `pos` — смещение относительно кости. Каждая цифра — отдельная ось
  (положительная X — вперёд, положительная Y — вправо, положительная Z — вверх).
- `ang` — поворот модели в градусах.

> **Важно:** оружия из секции `weapons` — это полный белый список back-оружия:
> сервер берёт его отсюда же (не из отдельного списка). Всё, чего нет в файле,
> за спину не попадёт и будет вести себя как обычное оружие Z-City
> (выбрасываться при неактивности).
>
> Чтобы добавить своё оружие за спину, допишите строку
> `weapon_class = { bone = ..., pos = ..., ang = ... },` в `weapons`.
> Чтобы убрать его — удалите строку. Секция `default` в файле оставлена как
> запасная позиция на случай битого файла и роли в отборе не играет.

После правки перезапустите сервер / смените карту (на клиенте достаточно
переподключиться). Синтаксис файла проверяется при загрузке: если в нём ошибка,
аддон не упадёт — он запишет предупреждение в консоль и будет использовать
встроенный список и встроенные позиции.
