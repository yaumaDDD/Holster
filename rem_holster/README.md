# Remorseim Back Holster

Отдельный аддон, который вешает милишки **Remorseim Gun Pack** за спину.
Работает рядом с `zcity_holster` и не конфликтует с ним: у каждого свой белый
список, свои позиции, свои сетевые каналы и свои хуки (максимум 2 предмета за
спиной — один ZCity + один Remorseim).

## Установка

1. Скопируйте папку `rem_holster` в `garrysmod/addons/`.
2. Перезапустите сервер / смените карту.

## Настройка позиций

Откройте **`lua/rem_holster/positions.lua`** — это единственный файл, который
определяет, какое Rem-оружие носится за спиной и как оно там выглядит.
Секция `weapons` — полный белый список; всё, чего в нём нет, за спину не
попадает (остальные Rem-меlee ведут себя как обычное оружие — выбрасываются
при неактивности, как в стоковом ZCity).

Формат записи такой же, как в `zcity_holster`:

```lua
weapon_rem_melee_hg_axe = {
    bone = "ValveBiped.Bip01_Spine2",
    pos  = Vector(2, 3.5, 0),
    ang  = Angle(90, 120, -5),
},
```

Модели берутся из самих оружий Remorseim по их путям (`WorldModelExchange`,
затем `WorldModel`) — отдельно прописывать их не нужно.

После правки перезапустите сервер / смените карту. Если в файле ошибка,
аддон не упадёт: предупреждение в консоль + встроенный список/позиции.

## Правила

- За спиной переносится максимум **один** Rem-предмет: при подборе нового
  старый выбрасывается.
- Двуручное оружие (TwoHanded / bigNoDrop) не выбрасывается при неявных дропах.
- Явный дроп (радиальное меню / бинд `drop`) работает как обычно.
