# Remorseim Back Holster

Аддон для Garry's Mod / Z-City: ближнее оружие из **Remorseim Gun Pack**
носится на спине, вместо того чтобы выбрасываться. Работает рядом с
`zcity_holster` и не конфликтует с ним.

## Возможности

- На спину можно положить только оружие из белого списка
  `lua/holster/positions.lua` (сейчас: копьё, про-копьё, кувалда, лопата,
  бензопила, пожарный топор, бита, алюминиевая бита, мачете, топорик, лом) —
  всё остальное (огнетушитель, нож-на-палке, бутылки и т.п.) туда не попадает.
- Одновременно носится только одно такое оружие: подобрав новое, вы выкидываете старое
  (у `zcity_holster` при этом свой отдельный слот).
- Оружие за спиной не выбрасывается при неявных дропах (например, когда ZCity сам
  выбрасывает переносимое оружие через `homigrad-dropholstered`) — аддон сам
  перехватывает этот стоковый хук, править игру не нужно.
- Двуручные стволы (`TwoHanded` / `bigNoDrop`) никогда не выбрасываются неявно.
  Двуручность милишки — это хват, а не защита: огнетушитель выбрасывается как обычное оружие.
- Явный дроп (команда `drop` / `dropweapon`, радиальное меню) выбрасывает только то
  оружие, которое просили выбросить, и ничего лишнего.
- Отображение (модель, кость, позиция, поворот) настраивается в отдельном файле
  **`lua/holster/positions.lua`** — код трогать не нужно.
- Пак **Remorseim Gun Pack не патчится**: ни его `.lua`, ни его модели не меняются.

## Структура

```
addon.json                                  -- метаданные аддона для GMod
lua/
  autorun/
    client/rem_holster_cl.lua               -- отрисовка модели на спине / на рагдолле
    server/rem_holster_sv.lua               -- правила переноса и дропа на сервере
  holster/
    positions.lua                           -- ← ГЛАВНЫЙ список back-оружия + позиции
```

## Установка

1. Положите папку в `garrysmod/addons/` и переименуйте её в `rem_holster`
   (или распакуйте `rem_holster.zip` туда же).
2. Перезапустите сервер / смените карту (или выполните `changelevel`).
   Ручные правки файлов Z-City **не требуются**.
3. Для выделенного сервера без мастерской файлы отдаются клиентам автоматически
   через `AddCSLuaFile` (см. начало `rem_holster_sv.lua`).

## Редактирование списка и позиций отображения

Откройте **`lua/holster/positions.lua`**. Это единственный файл, который определяет,
какое оружие можно носить за спиной, и как оно там выглядит. Формат такой же,
как в `zcity_holster`:

```lua
weapon_rem_melee_hg_axe = {
    bone = "ValveBiped.Bip01_Spine2",  -- кость, к которой крепится модель
    pos  = Vector(2, 3.5, 0),          -- смещение (вперёд, вправо, вверх)
    ang  = Angle(90, 120, -5),         -- поворот (pitch, yaw, roll), градусы
},
```

- `bone` — кость игрока; для спины это `ValveBiped.Bip01_Spine2`.
- `pos` — смещение относительно кости. Каждая цифра — отдельная ось
  (положительная X — вперёд, положительная Y — вправо, положительная Z — вверх).
- `ang` — поворот модели в градусах.

> **Важно:** оружия из секции `weapons` — это полный белый список back-оружия:
> сервер берёт его отсюда же (не из отдельного списка). Всё, чего нет в файле,
> за спину не попадёт и будет вести себя как обычное оружие.
>
> Чтобы добавить своё оружие за спину, допишите строку
> `weapon_class = { bone = ..., pos = ..., ang = ... },` в `weapons`.
> Чтобы убрать его — удалите строку. Секция `default` оставлена как
> запасная позиция на случай битого файла и роли в отборе не играет.

После правки перезапустите сервер / смените карту (на клиенте достаточно
переподключиться). Синтаксис файла проверяется при загрузке: если в нём ошибка,
аддон не упадёт — он запишет предупреждение в консоль и будет использовать
встроенный список и встроенные позиции.

## Какая модель ставится на спину

Модели берутся из самих оружий Remorseim по их путям: на спине стоит **та же
модель, что пак показывает в руках и на земле при выбрасывании** —
`WorldModelExchange` (своя модель реморсеима, например `models/tfa_nmrih/w_bat.mdl`
у биты) @ `modelscale`, иначе `WorldModelReal` (модель в руках) @ `modelscale2`,
иначе `WorldModel`.

Модель ставится своим **центром** (считается по костям модели), поэтому
`pos`/`ang` означают одно и то же для любого оружия — и для мировых моделей,
и для моделей с точкой привязки на ручке (как у алюминиевой биты).

Построение моделей сделано для всех оружий: при старте сервера и клиента
автоматически прекешируются модели ВСЕХ зарегистрированных оружий — баг
«моделька не рисуется» не повторится ни для одного оружия.
