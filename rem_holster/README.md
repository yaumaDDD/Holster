# Remorseim Back Holster

Система, которая вешает милишки **Remorseim Gun Pack** за спину.
Работает рядом с `zcity_holster` и не конфликтует с ним: у каждого свой белый
список, свои позиции, свои сетевые каналы и свои хуки (максимум 2 предмета за
спиной — один ZCity + один Remorseim).

> **Временная установка:** файлы кладутся прямо в директорию Гмода
> (`garrysmod/lua/...`), без папки-аддона. Позже всё будет собрано в аддон.

## Установка

1. Распакуйте архив `rem_holster.zip` в папку `garrysmod` — ту, где лежат
   `addons`, `gamemodes` и `lua`. Файлы должны лечь так (3 файла, 2 папки):

   ```
   garrysmod/lua/autorun/server/rem_holster_sv.lua
   garrysmod/lua/autorun/server/rem_holster_positions.lua
   garrysmod/lua/autorun/client/rem_holster_cl.lua
   ```

2. Перезапустите сервер / смените карту.

## Настройка позиций

Откройте **`lua/autorun/server/rem_holster_positions.lua`** (рядом с серверным
файлом) — это единственный файл, который определяет, какое Rem-оружие носится
за спиной и как оно там выглядит. Править нужно ТОЛЬКО на сервере — сервер сам
присылает позиции всем клиентам, на клиенте файл не нужен.
Секция `weapons` — полный белый список; всё, чего в нём нет, за спину не
попадает (остальные Rem-меlee ведут себя как обычное оружие — выбрасываются
при неактивности, как в стоковом ZCity).

Формат записи такой же, как в `zcity_holster`: `pos`/`ang` — смещение и
поворот относительно кости спины.

```lua
weapon_rem_melee_hg_axe = {
    bone = "ValveBiped.Bip01_Spine2",
    pos  = Vector(2, 3.5, 0),
    ang  = Angle(90, 120, -5),
},
```

Модели берутся из самих оружий Remorseim по их путям: на спине стоит **та же
модель, что пак показывает в руках и на земле при выбрасывании** —
`WorldModelExchange` (своя модель реморсеима, например `models/tfa_nmrih/w_bat.mdl`
у биты) @ `modelscale`, иначе `WorldModelReal` (модель в руках) @ `modelscale2`,
иначе `WorldModel`. Пак Remorseim Gun Pack не патчится: ни его `.lua`, ни его
модели не меняются, отображение оружия в игре система не трогает.

Построение моделей сделано для всех оружий: при старте сервера и клиента
автоматически прекешируются модели ВСЕХ зарегистрированных оружий (реморсеима
и любых других, включая будущие) — баг «моделька не рисуется» не повторится
ни для одного оружия.

После правки перезапустите сервер / смените карту. Если в файле ошибка,
система не упадёт: предупреждение в консоль + встроенный список/позиции.

## Правила

- За спиной переносится максимум **один** Rem-предмет: при подборе нового
  старый выбрасывается.
- Двуручное оружие (TwoHanded / bigNoDrop) не выбрасывается при неявных дропах.
- Явный дроп (радиальное меню / бинд `drop`) работает как обычно.
